# 🛒 Retail Data Analytics Portfolio Project

## 📌 Project Overview
This project demonstrates an end-to-end retail data analytics workflow using SQL, Python, and Power BI. The goal is to transform raw customer shopping data into meaningful business insights through data cleaning, analysis, and interactive dashboards.

## 🛠️ Tech Stack
- SQL
- Python (Pandas)
- Power BI
- Excel/CSV
